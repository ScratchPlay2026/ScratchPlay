Chapter 2: How to Start Your Game
On the BIOS screen, press U to upload a game, & you're all set! This is meant for IFrames for scratch projects.
Here's a step by step tutorial on how to upload a Scratch game.
Step 1: Go to the scratch project page.
Step 2: Highlight the project ID in the URL.
Step 3: Copy the highlighted part. You can do this by pressing Ctrl+C (Command+C on Mac).
Step 4: Go back to the ScratchPlay.
Step 5: Press U.
Step 6: Make sure you see a flashing vertical line in the input field, then paste the ID. You can do this by pressing Ctrl+V (Command+V on Mac).
Step 7: Press Enter.
Step 8: You should see an IFrame of the project. Click the green flag.

Chapter 3: Game Keys.
These are the 14 buttons you use: D-Pad (Up, down, left, & right), A (Space), B (Z), C (F), X (C), Y (X), Z (G), L (Q), & R (R).
