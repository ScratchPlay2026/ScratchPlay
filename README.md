Step 1: Go to the scratch project page. There are 2 methods you can use from here. The first method will be denoted with "a" after the step number. The
second method is denoted the same way as for the first method but it's "b", not "a".
Step 2a: Click on see inside.
Step 3a: Click on File > Save to your computer
Step 4a: Go to https://packager.turbowarp.org/
Step 5a: The default choice for the Select Project section will be File. Do not choose a different option. Click on Choose File.
Step 6a: Select the file for the project you downloaded in Step 3a.
Step 7a: You can figure this part out yourself. Trust your gut until you get to Enviroment.
Step 8a: Click on Plain HTML.
Step 9a (optional): Click on preview to test out the project before you convert your project.
Step 10a: Click on Package. This will do the converting & the downloading (if it doesn't download automatically, click on download.)
Step 11a: Go back to the ScratchPlay page.
Step 12a: Press U.
Step 13a: Choose your converted file.
Step 2b: Copy the link by highlighting the URL, & hitting Ctrl + C (Command + C on Mac) at the same time, or by highlighting, double-clicking (Tap with
2 fingers on a trackpad), & clicking on Copy.
Step 3b: Do step 4a.
Step 4b: In the Select File section, select Scratch Project ID or URL. It's not 2, but it's 1 big choice.
Step 5b: Paste the link by either pressing Ctrl + V (Command + V on Mac) or selecting the text box, double-clicking, then clicking on Paste.
Step 6b: Continue on Step 7a.

1장: ScratchPlay 설정하기
원하는 버전을 찾아서 선택하세요(최신 버전을 사용하는 것을 권장합니다).

2장: 게임 시작 방법
BIOS 화면에서 U 키를 눌러 게임을 업로드하면 모든 준비가 완료됩니다! 이 기능은 HTML 파일용입니다. 이 콘솔에서 사용할 수 있는 게임은 Scratch 게임입니다.
Scratch 게임은 .sb3 파일이므로 Scratch 게임을 업로드하는 방법을 단계별로 설명합니다.

1단계: Scratch 프로젝트 페이지로 이동합니다. 여기에서 사용할 수 있는 방법은 두 가지가 있습니다. 첫 번째 방법은 단계 번호 뒤에 "a"가 표시됩니다. 두 번째 방법은 첫 번째 방법과 동일하게 표기되지만, "a"가 아닌 "b"로 표시됩니다.
2a단계: "내부 보기"를 클릭합니다.

3a단계: "파일" > "컴퓨터에 저장"을 클릭합니다.
4a단계: https://packager.turbowarp.org/ 로 이동합니다.
5a단계: "프로젝트 선택" 섹션의 기본 선택 항목은 "파일"입니다. 다른 옵션을 선택하지 마십시오. "파일 선택"을 클릭합니다.
6a단계: 3a단계에서 다운로드한 프로젝트 파일을 선택합니다.

7a단계: 이 부분은 직접 진행해도 됩니다. "환경" 단계에 도달할 때까지는 직감을 믿으세요.

8a단계: "일반 HTML"을 클릭합니다.
9a단계(선택 사항): 프로젝트를 변환하기 전에 "미리 보기"를 클릭하여 프로젝트를 테스트합니다.

10a단계: "패키지"를 클릭합니다. 그러면 변환 및 다운로드가 진행됩니다(자동으로 다운로드되지 않으면 "다운로드"를 클릭합니다).
11a단계: ScratchPlay 페이지로 돌아갑니다.

12a단계: U 키를 누릅니다.
13a단계: 변환된 파일을 선택합니다.

2b단계: URL을 선택한 다음 Ctrl + C(Mac에서는 Command + C)를 동시에 눌러 링크를 복사하거나, 선택한 후 두 번 클릭(트랙패드에서는 두 손가락으로 탭)하고 복사를 클릭합니다.

3b단계: 4a단계를 수행합니다.

4b단계: 파일 선택 섹션에서 Scratch 프로젝트 ID 또는 URL을 선택합니다. 두 개가 아니라 하나의 큰 선택 항목입니다.

5b단계: Ctrl + V(Mac에서는 Command + V)를 누르거나 텍스트 상자를 선택하고 두 번 클릭한 다음 붙여넣기를 클릭하여 링크를 붙여넣습니다.

6b단계: 7a단계를 계속합니다.

3장: 게임 키
게임을 플레이하는 데 필요한 9개의 필수 키입니다. 다음 키들이 필요합니다: ←, →, ↑, ↓, ⎵ (스페이스바), Z, X, C, V.

4장: 출시 예정
스크래치 비디오 게임: 스크래치 3.0 쇼 더 무비를 기반으로 한 재미있는 플랫폼 게임입니다. 2027년 6월 스크래치플레이에서 출시됩니다.
